# 问题 2：训练种子与遮挡种子 2028 复核

主模型检查点：`problem2/outputs/dropout03_lr_drop/seed2028/best.pt`。其训练种子为 2028、dropout 为 0.3、隐藏维度为 128，第 6 轮起学习率由 `2e-4` 降至 `5e-5`，验证规则选中第 9 轮。

## 缺失实验

```bash
python problem2/main.py robustness --split valid --seeds 5 --bootstrap 200 \
  --mask-seed-base 2028 --batch-size 128 \
  --checkpoint problem2/outputs/dropout03_lr_drop/seed2028/best.pt \
  --out problem2/outputs/seed2028_reanalysis/robustness
```

该命令覆盖 7 种缺失模态组合、5 个缺失比例与 4 种位置。固定位置和第一次随机位置使用遮挡种子 2028；另 4 次随机位置分别使用 2029–2032。`valid_robustness_maskseed2028_only.csv` 提取严格使用种子 2028 的 140 个条件；`valid_robustness.csv` 含全部 280 个条件。

## 消融实验

除 `fixed_gate` 使用上述已核验的主模型权重外，其余四组用相同超参数重新训练，仅切换 `--ablation`：

```bash
for variant in none no_block no_reconstruction no_consistency; do
  python problem2/main.py train \
    --out "problem2/outputs/seed2028_reanalysis/ablations/$variant" \
    --epochs 12 --batch-size 32 --hidden 128 --heads 4 \
    --dropout 0.3 --lr 0.0002 --patience 4 --seed 2028 \
    --ablation "$variant" --lr-drop-epoch 6 --lr-drop-factor 0.25
done
python problem2/ablation_seed2028_report.py
```

`ablation_seed2028_report.py` 从各组保存的最佳检查点重新计算验证集完整输入和 30% TAV 缺失输入指标，并与逐轮日志核对。测试集未参与架构消融比较。最终模型保持用户已选定的 `fixed_gate` 检查点。
