# 最终模型按数据划分与情感标签的指标

每个标签的 Accuracy 采用该标签对其余标签的一对其余准确率；
Macro F1 采用该标签对其余标签的二分类宏平均 F1。
同时列出该标签的类内准确率（等于召回率）和该类 F1，便于识别一对其余指标受其他类样本影响的情况。
MAE 仅在真实标签属于该类的样本上计算情感强度绝对误差。
总体 Macro F1 则按三个情感类的 F1 取平均。
